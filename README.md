# Instituto Esperança

Site institucional desenvolvido na Experiência Prática IV de Front-end.

## Tecnologias
- HTML5
- CSS3
- JavaScript (ES Modules)
- Vite
- SweetAlert2 via CDN
- localStorage

## Execução local

```bash
npm install
npm run dev
```

## Build de produção

```bash
npm run build
npm run preview
```

O comando `npm run build` gera a versão otimizada na pasta `dist/`.

## Estrutura

- `index.html`: entrada da aplicação.
- `src/css/`: estilos.
- `src/js/`: módulos JavaScript.
- `public/imagens/`: imagens estáticas otimizadas.
- `vite.config.js`: configuração do Vite.

## Versionamento

O projeto segue GitFlow, com `main`, `develop`, `feature/*` e `hotfix/*`, além de commits semânticos e versionamento semântico.
